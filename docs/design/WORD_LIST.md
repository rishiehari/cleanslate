# Word list (ux-writing)

| Use | Instead of | Meaning |
|---|---|---|
| **Keep** | save, retain | The photo that stays in your library |
| **Delete** | remove, purge, clean | Photos you chose to delete (only after the Apple prompt) |
| **Approve** | confirm, accept | Add the marked photos to your tray. It does **not** delete |
| **Skip** | ignore, dismiss | Leave this group alone for now |
| **Undo** | revert | Reverse the last approve or skip |
| **Tray** ("Ready to delete") | queue, basket, cart | Photos you approved, waiting for your final delete |
| **Copy** | duplicate, redundant, candidate | A byte-identical file |
| **Similar photo / similar shots** | near-duplicate | Looks alike, but not identical. You decide |
| **Free up** | reclaim, recover | Space you could get back |
| **Verified** | confirmed, guaranteed | File size read from the actual photo files |

Never in UI copy: *asset, resource, revision, hash, candidate, fingerprint, logical bytes, junk, garbage*.

Voice: calm, plain, never alarming. Say what happens and what it costs. Put legal/technical caveats in "Things to know" or a sheet, not on every screen.
Alerts: title + buttons alone must explain the situation. Lead with the why ("To find copies, CleanSlate needs to look at your photos").
